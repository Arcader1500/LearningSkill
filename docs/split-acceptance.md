# Authoring/tutoring split acceptance

The disposable sample in tests/authoring.test.mjs instantiates the new templates with two lessons, quiz-1/quiz-2 and three assignments: required a and optional b at the first checkpoint, and required c after the final lesson. The test checks local links, one Practice and next steps section per lesson, shared workflow placement and absence of unresolved placeholders/tutor-policy text. It injects and detects an answer-path mismatch, duplicated workflow and a negative-input specification/check mismatch, fixes them, then initializes/resumes via the unchanged state implementation. Files are removed after the test; existing learner courses are not changed. This is a bounded authored example with explicit review assertions, not proof of autonomous tutor quality or a general natural-language linter. No external setup commands or runtime examples were executed for that sample.

The workflow integration test runs creation/bootstrap from each host's create-course helper, then starts a separate learn helper process for resume. It preserves intake and the saved next action without chat history. The packaging integration test exercises legacy string-pending assessment state, explicit answer capture, grading and fresh-process resume for both hosts. Existing submission tests cover immutable snapshots and pending submission behavior. Both packaged skills contain canonical copies of the same protocol and source implementation; validation checks relative resources/imports, canonical contents and frontmatter for each host.

The Cargo grading example in eval/criterion-evidence.json supplies a fixed three-part essential rubric and partial, equivalent complete and unsupported responses. The assessment test records those actual responses and verifies derived essential pass only for full independent credit. Semantic evidence matching remains tutor-owned; the helper validates grade structure and derives pass, without claiming to understand prose or rejecting an otherwise structurally valid but semantically incorrect model score.

Live Codex/Antigravity skill discovery, actual teaching/grading behavior, native question UI, AGY strict validation and genuine interactive cross-host resume were not run in this environment. Automated helper checks are reported separately from those host checks. Existing installer/verification history in README.md is historical, not a live check of this branch.

Two existing symlink fixtures needed portable inputs to exercise their intended assertions on this runtime: the path-escape target now exists, and packaging points a required asset at an outside file rather than inserting an unused extra directory. No path-resolution or state code was changed.
